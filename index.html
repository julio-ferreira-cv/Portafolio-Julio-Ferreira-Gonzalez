Guía: Alojamiento Gratis en GitHub Pages

Publica esta página web profesional con tu propio enlace único en menos de 5 minutos.

1 Crea tu cuenta o inicia sesión en GitHub

Ingresa a github.com e inicia sesión.

2 Crea un nuevo Repositorio

Haz clic en el botón verde **"New"** para crear un nuevo repositorio. Nómbralo por ejemplo: mi-portafolio o julio-regoli-cv. Asegúrate de que sea **Público**.

3 Sube los archivos

Guarda todo este código en un archivo llamado obligatoriamente index.html. Sube index.html y tu foto de perfil a la raíz del repositorio usando la opción **"Upload files"**.

4 Activa GitHub Pages

En la pestaña **Settings** (Configuración) de tu repositorio → Menú lateral **Pages** → En **Branch** selecciona main y guarda. ¡En 1 minuto tendrás tu sitio activo en https://tu-usuario.github.io/mi-portafolio!
